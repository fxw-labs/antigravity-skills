# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `antigravity-skills`, please do not report it publicly via GitHub Issues.

Instead, please send an email directly to **fxw.xlab@gmail.com** with details including:

1. A clear description of the vulnerability.
2. Steps or minimal reproduction script to reproduce the issue.
3. The potential impact on user systems or configurations.

We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
