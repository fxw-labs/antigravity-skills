# Triage Labels

The canonical triage label vocabulary used across this repository:

- `needs-triage`: Newly submitted issue or request awaiting initial assessment.
- `needs-info`: Blocked on answers or clarification from the author.
- `ready-for-agent`: Fully specified and ready for automated agent implementation.
- `ready-for-human`: Requires manual human intervention or external review.
- `wontfix`: Out of scope or rejected.
